================================================================================
                                样例使用说明
                             Sample Description
================================================================================
功能描述：
此样例通过软件SPI（GPIOビットバング）驱动 Pmod-LCD-0.96 v1.0 モジュール
（LCDコントローラ: ST7735S，解像度: 160x80，RGB565）を初期化し，画面全体を
オレンジ一色で塗りつぶします．基板上の4個のLEDは起動ステージ番号を
バイナリ表示し，どこまで進んだかをスコープ無しで切り分けられます．

Function descriptions:
This example drives the Pmod-LCD-0.96 v1.0 module (ST7735S controller,
160x80, RGB565) over software (bit-banged) SPI, initialises it and fills the
whole panel with a single orange colour. The four on-board LEDs show the
bring-up stage number in binary so a failure can be localised without a scope.

--------------------------------------------------------------------------------
接続 / Wiring
--------------------------------------------------------------------------------
    PY32E407 | LCDモジュール (Pmod-LCD-0.96)
    ---------+------------------------------
    PD3      | CS
    PD5      | SDA (MOSI)
    PD6      | DC (RS)
    PD4      | SCK
    PC8      | RST

    ※ 現在の既定 (LCD096_PMOD_ROW = 2) です．
      もう一つの挿入方向 (row 1) は下の表を参照してください．

    ※ すべてプッシュプル出力のGPIOとしてビットバングしています．
      SPIモード0 (CPOL=0, CPHA=0) です．

--------------------------------------------------------------------------------
Pmod の挿入方向 / Pmod insertion direction
--------------------------------------------------------------------------------
    Pmod モジュールは 12 ピンコネクタなので「表向き」「裏向き」の
    どちらでも挿入でき，電気的にはどちらも有効です．そのためドライバは
    2通りのピンマップを持ち，LCD096_SetPmodRow(1|2) で選択します．

    基板 J3 (シルク "I2C3") のパッド -> MCU:
      1列目: pin1 PD7, pin2 PB6, pin3 PC8, pin4 PC9, pin5 GND, pin6 +3V3
      2列目: pin7 PD3, pin8 PD5, pin9 PD6, pin10 PD4, pin11 GND, pin12 +3V3

    モジュールのシグナル列は CS, MOSI, DC, CLK, GND, VCC で，その並びは
    基板の 1列目と一致します．RESET は反対側の列にあり，DC の真向かいに
    位置します（CLK の真向かいではありません）．したがって:

      row 1 (シルクのラベルどおり):
        CS=PD7  MOSI=PB6  DC=PC8  CLK=PC9  RST=PD6 (J3 pin9)
      row 2 (既定, モジュールを180度回転):
        CS=PD3  MOSI=PD5  DC=PD6  CLK=PD4  RST=PC8 (J3 pin3)

    ※ J3 pin10 = PD4 はモジュールの RESET ではありません．どちらの向きでも
      モジュールの未使用ピン (pin3) に当たります．PD4 を動かしてもパネルは
      変化しません．

    main.c は起動時まず row 2 を 3 秒ホールドして白を表示し，続いて row 1 を
    3 秒ホールドします．どちらの向きが本物かは「白く光った瞬間」で判断
    できます．その後は両方の向きで色を順に切り替え続けます（白→赤→緑→
    青→橙）．実際に挿入されている向きのパスだけがパネルを描き替えるので，
    もう一方のパスは上書きされて見えません．色の並びがおかしい場合は
    パネルの色極性 (LCD096_USE_INVON) を疑ってください．

--------------------------------------------------------------------------------
ピン確認 / Pin identification (scope 不要)
--------------------------------------------------------------------------------
    lcd096.h の APP_RUN_PIN_SELFTEST を 1 にすると，CS / SDA / DC /
    SCK / RST を1本ずつ HIGH にします（他は LOW）．テスタや素のLEDを
    LCD 側のピンに当てれば，どの MCU ピンにつながっているか確定できます．
    ステージ 81..85 が LED に表示されます．

--------------------------------------------------------------------------------
ファイル構成 / Files
--------------------------------------------------------------------------------
    Src/main.c       : メイン（LCD初期化 + オレンジ塗りつぶし + LED点滅）
    Src/lcd096.c     : ST7735S ソフトウェアSPIドライバ本体
    Inc/lcd096.h     : ピン定義・色定義・API宣言

--------------------------------------------------------------------------------
主なAPI / API overview
--------------------------------------------------------------------------------
    void LCD096_SetPmodRow(uint8_t row);                 // 1 or 2
    void LCD096_Init(void);
    void LCD096_PinSelfTest(uint32_t hold_ms);           // ピン確認用
    void LCD096_FillScreen(uint16_t color);              // 例: LCD096_ORANGE
    void LCD096_FillRect(uint16_t x, uint16_t y, uint16_t w, uint16_t h,
                         uint16_t color);
    void LCD096_DrawImage(uint16_t x, uint16_t y, uint16_t w, uint16_t h,
                          const uint16_t *pixels);

    色はRGB565です（LCD096_ORANGE = 0xFC00）．

    パネル調整用マクロ (lcd096.h):
      LCD096_PMOD_ROW     : 既定の挿入方向 (1 or 2)
      LCD096_MADCTL_VALUE : MADCTL(0x36) の値 (既定 0x00)
      LCD096_USE_INVON    : 0=INVOFF, 1=INVON (色が反転するパネル用)

--------------------------------------------------------------------------------
ビルド / Build
--------------------------------------------------------------------------------
    ※ ビルドには Puya SDK の Drivers ツリーが必要です．このフォルダから
      5階層上（例: H:\Drivers）に Drivers/BSP, Drivers/CMSIS,
      Drivers/PY32E407_HAL_Driver を配置してください．
      PuyaSDE の sdk\example\PY32E407_Firmware_*.zip を展開して
      Drivers ツリーをコピーすれば用意できます．

    EIDE でビルドするか，EIDE フォルダで:

        > make           ( arm-none-eabi-gcc にPATHを通して実行 )

    make は Project/Project.elf, Project.hex, Project.bin を生成します．

--------------------------------------------------------------------------------
書き込み / Flash
--------------------------------------------------------------------------------
    EIDE の書き込みタスク (pyOCD / JLink) を使用します．

注意事项 / Notes：
  ・ST7735S の初期化は COLMOD=0x05 (RGB565), MADCTL=LCD096_MADCTL_VALUE,
    極性は INVOFF (LCD096_USE_INVON=0) を既定としています．
  ・CS はコマンド＋パラメータの間，LOW に保持しています（4線シリアルの要件）．
  ・塗りつぶしは可視領域 160x80 だけでなくフレームメモリ全域 132x162 に
    書き込むため，ガラスのオフセットや MADCTL の回転に依存しません．
  ・このパネルは ST7735S ですが，モジュールによってはオフセット（赤タブ/
    緑タブ）が異なる場合があります．色がずれる場合は CASET/RASET の開始
    アドレスを調整してください．
  ・LED 表示 (bit3..bit0 = LED4..LED1, ACTIVE LOW):
      1..11 = 起動ステージ, 81..85 = ピンセルフテスト
      11 が点滅していればファームウェアは完走しており，原因は LCD 側です．
